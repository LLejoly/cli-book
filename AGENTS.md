# For AI agents contributing to this book

Before adding or changing a page, follow `.claude/skills/add-command-page/SKILL.md`.
The house rules are in `STYLE.md`. Run `python3 tools/check_pages.py` before you submit; it must pass.

To translate a page or start a new language, follow `.claude/skills/translate-page/SKILL.md`
and `i18n/README.md`. Commands and examples never change between languages.
