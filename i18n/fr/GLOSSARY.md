# Glossaire français

Every French page uses these words, so the Study reads as one place.
Translate the meaning and the warmth, not word for word. Keep the tone of
STYLE.md: calm, short sentences, "vous", no hype, no emoji.

## What never changes

- Commands, flags, file names, paths, and everything inside code spans and
  `console` blocks stay exactly as in English, outputs included (`notes.txt`
  still says "buy flour"). The reader types the same thing in every language.
- The first column of the margin-notes table (what you write) stays as is.
